# Offline Image Swap

A lightweight, local, offline-first image and GIF swapper built specifically for low-spec systems (compatible with Windows 8.1, 2GB RAM, and integrated Intel graphics with no CUDA requirements).

## Requirements
- Python 3.8+
- Pillow library

## Installation
1. Clone or download this repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
